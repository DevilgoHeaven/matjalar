# 60개 시드 조합 입력 템플릿 (PRD §13 콜드 스타트)

> 작성일: 2026-05-17 / PRD §5 v1 MVP — 출시 최소 데이터
> 운영자(`@DevilgoHeaven`) admin 계정으로 `/admin/seed` 폼에 입력

---

## 입력 정책 (R-15·R-16·plan §13)

- **운영자 추천 메모**(`combos.seed_comment`, 140자) **필수** 입력 — "운영자 추천 메모" 라벨로 카드에 노출
- 외부 블로그·디시·유튜브 댓글 문장 **그대로 복사 금지** — 운영자가 직접 한 줄로 작성
- 사이즈/세트는 `menu_variants` (15cm/30cm/샐러드) + `세트 여부` 옵션 그룹으로 표현 (v2.2 patch 1)
- `combo_signature` 는 등록 시 자동 계산 (SHA256, NFC 정규화)
- 등록 직후 `admin/approveCombo` 액션으로 본인 승인 → `status=published`

## 5개 상세 샘플 (입력 예시)

각 입력 시 `/admin/seed` 폼에서:
1. 브랜드 → 서브웨이
2. 메뉴 → 아래 메뉴
3. 사이즈 변형 → 아래 사이즈
4. 빵/치즈/야채(include)/야채(exclude)/추가/소스/세트 차례로 선택
5. 운영자 추천 메모 입력 (필수)
6. 태그 선택
7. 제출 → 본인 admin 으로 즉시 승인

## 입력 후 검증

각 조합 등록 후 다음 SQL 1회 실행으로 검증:
```sql
select count(*) as total,
       count(*) filter (where status = 'published') as published,
       count(distinct combo_signature) as unique_signatures
  from public.combos;
-- 기대: total=60, published=60, unique_signatures=60 (signature 충돌 없음)
```

`/admin/seed` 페이지 또는 `/admin/combos` 승인 큐에서 진행률 확인.
